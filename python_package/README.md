# HEAMS: Python package

This directory holds the Python package (`heams`, with the `heams` command line)
for HEAMS (Holistic Evaluation of Agent Memory Systems).

See the [repository README](../README.md) for what the project is, how to
install it, and a quickstart, and the
[documentation](https://milatechtransfer.github.io/heams/) for
everything else. The documentation is built from [`docs/`](docs/).
